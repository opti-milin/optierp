Exporting Your Tally Data

A step-by-step guide to producing the two files OptiReach needs from TallyPrime, so your books come across complete and accurate the first time.

What we need from you

Two files, exported in this order. The order matters.

File What it contains Why we need it
1. Masters Ledgers, groups, stock items, units, godowns, parties, tax ledgers These are the names everything else refers to. Without them a transaction naming "ABC Traders" or "Laptop Computer" has nothing to point at.
2. Transactions Your vouchers — sales, purchases, receipts, payments, journals The actual entries in your books for the period being moved across.
Most common mistake Exporting only the transactions. On its own it is unusable — every ledger and item it mentions will be unrecognised. Always send both files.

Before you start

  • Open TallyPrime and load the company you want to send.
  • Check the company name on screen is the right one — if you keep several companies, it is easy to export the wrong books.
  • Decide the period. If unsure, send one full financial year.
  • Have a folder ready to save into, such as your Desktop.

Export 1 — Masters

  1. From the Gateway of Tally, press Alt + E to open the Export menu.
  2. Choose Masters.
  3. In the configuration screen, set Type of Masters to All Masters.
  4. Set File Format to XML.
  5. Set the file name to YourCompany-Masters.xml
  6. Note the folder shown in Export Location, then press Enter to export.
Check this one carefully Type of Masters must say All Masters — not Accounting Masters. If it says Accounting Masters you will get your ledgers but no stock items, and every product on your invoices will come across as unknown. This is the single most frequent problem we see.

Export 2 — Transactions

  1. From the Gateway of Tally, go to Display More Reports → Day Book.
  2. Press Alt + F2 to set the period, and enter the from and to dates you want to send.
  3. Press Alt + E and choose Current.
  4. Set File Format to XML.
  5. Set the file name to include the period, for example YourCompany-Transactions-Apr2025-Mar2026.xml
  6. Press Enter to export.
Large books? If the period covers more than about 10,000 vouchers, export it in quarters — one file per quarter, each named with its period. Several smaller files are easier to check and far easier to correct if something needs redoing. Send them all together.

Settings that must be right

Setting Must be What goes wrong otherwise
File Format XML Excel and CSV drop the internal reference numbers, bill-wise details and warehouse information. Your invoices would not match up to their payments.
Type of Masters All Masters Accounting Masters leaves out every stock item, unit and godown.
Period (Day Book) The full range you want moved Tally exports only what is on screen. A one-day period exports one day.
Company The correct one With several companies loaded it is easy to export the wrong books.

Check your files before sending

Two minutes here saves a round trip. Right-click each file, choose Open with → Notepad, then use Ctrl + F to search for the text below.

In the Masters file

  • Search for <STOCKITEM — you should find matches (if you have no stock items at all, skip this)
  • Search for <LEDGER — you should find many matches
  • Search for <GROUP — you should find many matches

No <STOCKITEM matches but you do sell products? Type of Masters was set to Accounting Masters. Export it again as All Masters.

In the Transactions file

  • Search for <VOUCHER — you should find many matches
  • Check the file size is not near-empty — a few KB usually means the Day Book period was wrong

Both files

  • The file name ends in .xml, not .csv or .xlsx
  • The company name near the top of the file is the right company

Sending the files

  • Put both files in one folder, right-click it and choose Send to → Compressed (zipped) folder.
  • Email the ZIP to your OptiReach contact. XML files are often blocked by email filters when sent loose, which is why we ask for a ZIP.
  • If the ZIP is too large to email, tell us and we will send you a secure upload link.

If something does not look right

What you see What it means
No Type of Masters option You are exporting from inside a report rather than the Gateway. Press Esc back to the Gateway of Tally and start again.
Export file is very small Usually an empty period in the Day Book, or the wrong company. Check both and export again.
Cannot find the exported file Look at Export Location on the export screen — it shows the exact folder Tally saved to.
Tally offers only Excel or PDF Scroll the File Format list; XML is there. If it genuinely is not, tell us your Tally version and we will advise.

About your data

These files contain your accounting records. We treat them accordingly:

  • They are used only to load your books into OptiReach and to verify the result matches Tally.
  • They are stored securely and are not shared with anyone outside the engagement.
  • Nothing is written to your live Tally company. Exporting is read-only — it cannot alter or damage your books.
  • Tell us when you would like the source files deleted and we will confirm once done.
Not sure about any step? Stop and ask before exporting again. Sending us a file you are unsure about is fine — we check every file on arrival and will tell you quickly if anything is missing.
